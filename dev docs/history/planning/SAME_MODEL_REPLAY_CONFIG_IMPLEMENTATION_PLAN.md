# 同模型保存检查与重跑配置实施计划（已完成）

日期：2026-10-09。状态：源码实施与隔离验收完成，已归档。用户已确认默认重跑使用更新后的同模型必要配置，无需新增配置选择；本计划是本轮明确工作包，不授权生产加载、真实模型调用、视频重跑、迁移、提交或推送。

## 1. 问题与目标

模型保存当前只写入 Profile；本地路由的接口能力可能为空，直到视频已完成下载和 ASR 才在校对请求前暂停。Job 的提交快照保存整个 Profile，更新全局能力后普通重试、步骤续跑和完整重跑仍复用旧值。目标是把必要的接口检查移到保存阶段，并在重跑入队时刷新同模型的必要执行配置，同时保留提交意图、生成参数、证据和历史记录。

## 2. 配置粒度与冻结规则

| 类别 | 字段/范围 | 规则 |
| --- | --- | --- |
| 身份 | Profile ID、实际 model、provider、规范化 base_url、接入方式、推理位置 | 原模型身份固定；同 ID 被改成不同身份、删除或禁用时拒绝相关重跑，不跟随当前全局路由 |
| 接口 | interface_capabilities、实际 JSON 支持与参数字段映射 | 采用当前已保存且绑定一致的能力；不信任客户端提交的能力声明，不补造业务 Probe |
| 运行 | Profile 超时/间隔/并发/限速/重试/熔断；阶段超时/重试；转写超时；通用请求间隔/重试参数 | 入队时按白名单刷新；任务显式覆盖仍优先；任务总预算/尝试上限不扩大 |
| 语义 | temperature、thinking、输出/输入上限、Prompt、领域包、分块、模型路由、质量规则 | 沿用原有效快照；已有显式笔记换模型恢复仍作为独立授权操作保留 |
| Secret | API Key 等 | 保存前目录检查使用本次凭据，检查成功才写 Secret Store；执行时仍从 Secret Store 读取，不进 SQLite/审计/Job |

原 ai_submission_config 不变；新增无密钥 ai_execution_config 保存必要覆盖的设置项（项内语义字段保留原值），记录执行版本、时间、来源配置更新时间、字段差异及有效配置指纹；前次执行配置追加到 ai_execution_history。配置读取优先级：本次执行配置（已合并有效显式恢复） > 显式恢复 > 原提交快照；重跑先以原提交/有效恢复配置为基础重新生成执行配置。运行中不读全局可变设置。无提交快照的旧任务保持兼容行为，不伪造历史提交配置。

## 3. 实施步骤

1. **保存公共检查**：create/update 共用本地路由检查；新建、身份/凭据变化、缺少能力或手动刷新后自动 GET 接口/模型目录。无变化且已有效的能力复用。失败返回明确错误，旧配置和旧凭据不变；DIRECT 不触发目录请求。保留真实测试与业务 Probe 的独立入口。
2. **早期准入**：视频提交在 Source/Job 写入和下载/ASR 前检查将使用的核心文本阶段本地路由能力；只检查配置，不发推理请求。能力缺失、模型绑定不一致、系统指令不支持时返回明确原因，不阻止未使用的模型。
3. **执行快照公共函数**：按白名单合并同模型必要字段；保留语义、原路由、显式覆盖和原预算；返回安全差异用于审计。当前模型身份变化、模型删除/禁用、必要能力缺失时无状态变更地拒绝入队。
4. **所有重跑入口**：普通 retry、步骤续跑、终态完整重跑均调用公共函数；活跃任务完整重跑先冻结待执行配置，等待旧 run fence/租约安全退出后使用该配置，不再读取更新后的全局值。已有笔记显式换模型恢复与完整重跑清除恢复规则兼容。
5. **预算与缓存**：累计 Token/远程尝试使用同 Job 的历史 Audit，刷新配置不扩大限额或删除历史；单次运行耗时边界保留。接口指纹继续进入缓存键，刷新后受影响阶段重新运行；步骤续跑之前的有效 ASR/Artifact 保留，语义规则和证据校验不降级。
6. **前端说明与文档**：不新增重跑选择项；保存/等待说明反映自动目录检查，重跑文案说明同模型必要配置刷新。保持现有共享组件和本轮前置 UI 改动。修订 job-policy、本地路由契约、冻结清单和当前实施状态，计划完成后归档；不自动写交接。

## 4. 验收条件

- 保存 LOCAL_ROUTER 自动读取并落库匹配能力；HTTP 请求仅目录 GET。名称/运行参数更新复用有效能力；换模型/地址/凭据重新检查；读取失败旧配置/凭据不变；DIRECT 不读 Mux 目录。
- 核心阶段能力缺失时提交失败且无新 Source/Job，无下载/ASR/模型调用；能力目录不等于业务质量。
- 旧 Job 在相同模型补齐能力后普通/步骤/完整重跑可入队；temperature、输出上限、Prompt、分块、原路由与显式覆盖不被当前全局值覆盖；原提交快照逐字段不变。
- 任一相关模型身份变更、禁用/删除、能力绑定错误均安全失败；未引用模型不影响重跑。
- 入队后再改全局设置不改变这次执行；连续重跑有可追溯的执行版本/安全差异；延迟完整重跑在旧 Worker 释放前不生效，释放后复用已冻结配置。
- 既有笔记模型恢复、无快照旧任务、run fence、取消、累计预算、缓存指纹、raw/corrected 身份回归通过；Secret 不入执行快照/差异。
- 先目标 pytest/Ruff，再工作包末一次全量后端与前端 verify；有前端行为/说明变更则用隔离数据和模拟目录做 PC/390px Browser 验收，禁止生产配置写入或真实推理。最后 git diff --check。

## 5. 边界与交付

无新增依赖、无数据库 Schema 变化、无历史迁移修改。模型接口能力保存失败不会以绕过门禁方式放行；参数刷新不自动切换模型、不改变业务门禁、不自动确认 POI。交付为源码、离线/隔离浏览器证据及同步契约；生产加载与真实视频恢复仍明确未执行。
