# X｜可选的单平台来源试点

返回[总览](README.md)，遵循[执行契约](09_AGENT_EXECUTION.md)。承接原 06 WP2 和新平台 WP3；默认未启动，不是完成其他包后的自动下一步。

## 启动条件与范围

用户明确选一个平台、内容类型和能力档位，提供合法可用样本/账号条件，并确定联网/下载/API 费用上限。没有选择时只记录待决策，不让 Agent 任意选择平台。技术契约和平台调研唯一正文是[已有 Adapter 计划](../SOCIAL_LINK_ADAPTER_FEASIBILITY_PLAN.md)；其日期性权限/价格在实施时核对官方资料，不能把 10 月调研视作现时保证。

按“预览→正文→视频证据”分档，每次仅交付选定档位。正文与视频字幕/ASR 各有来源；无字幕但有合法媒体可走既有授权 ASR，缺媒体/正文时仅预览或待补充。不做全站抓取、评论/私信/直播/付费绕过、登录集群或自动跨平台补抓。单平台探索最多沿旧计划的两个人天窗口；失败则 NO_GO 或限定预览，不能无限扩张。

## 实施与验收

X1 核对已有注册表/协议和安全边界，输出可取得字段、缺失原因及权限；X2 在 Worker 内实现一个 adapter，复用 Capture/Snapshot/Evidence 与现有取消/预算/缓存；X3 测试身份、重定向、敏感参数、限流/取消、过期权限及正文完整性。新依赖只在无法复用时提出必要性；新 Schema 使用新 Alembic，生产迁移另授权。

真实样本门槛沿旧计划：选定平台至少 10 条可访问正样本和 5 条受限/错误样本、两个不同日期复验；报告每档实际成功率与样本量。达到声明档位的正样本建议 ≥90%，身份/安全/证据硬门禁全部通过；不满足就缩小声明范围或不启用，不能声称全站可靠。真实 ASR/LLM 不由来源读取授权连带允许，单列调用预算。

交付能力矩阵、go/no-go、复现入口、限制及关闭该 adapter 的回退路径。外部条件缺失时可完成离线 adapter 测试，但真实验收保持 NOT_RUN；新平台失败不阻塞 S 已有来源修复或其他包结项。
