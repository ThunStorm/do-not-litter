# v0.4 视频地点与全国地图审阅稿

本目录是 v0.4 的代码原生界面实施依据，延续暖白纸张、墨黑正文、朱砂强调与低饱和地图的既有系统。图稿不作为页面背景使用。

| 文件 | 页面 | 已冻结交互 |
| --- | --- | --- |
| `23-national-map-marker-v0.4.svg` | 中国大陆地图总览 | 首次全国视野、按视野聚合、Marker 浮层、来源数、隐藏与地点详情入口 |
| `24-amap-settings-v0.4.svg` | 高德配置 | JS Key、Security Code、Web 服务 Key、独立测试与诊断结果 |

实现约束：地图首次使用中国大陆 bbox，后续恢复当前浏览器会话视野；自动 Marker 只能隐藏其地图投影，用户 Marker 为可恢复软删除；地点、来源、Claim、Evidence 与地点笔记不会因 Marker 操作被删除。截图展示必须使用持久化的受保护 API URL，不能暴露服务器绝对文件路径。
